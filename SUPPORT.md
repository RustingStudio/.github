# Getting help

Start with the project's README, installation instructions, examples, and existing issues. Platform requirements and available features vary by project.

| Project | Documentation | Questions and bug reports |
| --- | --- | --- |
| RustingEngine | [Getting started](https://github.com/RustingStudio/RustingEngine/blob/main/docs/getting-started.md) · [Documentation](https://github.com/RustingStudio/RustingEngine/blob/main/docs/README.md) | [Issues](https://github.com/RustingStudio/RustingEngine/issues) |
| RustingBrain | [README](https://github.com/RustingStudio/RustingBrain#readme) · [Tutorials](https://github.com/RustingStudio/RustingBrain/blob/main/tutorials/README.md) | [Issues](https://github.com/RustingStudio/RustingBrain/issues) |
| RustingShader | [Requirements & installation](https://github.com/RustingStudio/RustingShader#requirements) | [Issues](https://github.com/RustingStudio/RustingShader/issues) |

For another RustingStudio project, use that repository's own issue tracker.

When asking a question, describe what you're trying to do, what you've tried, and where you're stuck. Include the version or commit and your environment; GPU-related questions should include your graphics card and driver. Share the smallest relevant example and remove secrets from logs.

For organization profile or shared documentation problems, use [this repository's issues](https://github.com/RustingStudio/.github/issues).

Help is provided as maintainers are available. There is no guaranteed response time. For community conduct concerns, use the private contact in our [conduct guidelines](https://github.com/RustingStudio/.github/blob/main/CODE_OF_CONDUCT.md).
