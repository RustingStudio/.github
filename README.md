# RustingStudio community

This repository contains the [RustingStudio organization profile](https://github.com/RustingStudio), its visual assets, and shared community guidance.

## Explore the projects

- [RustingEngine](https://github.com/RustingStudio/RustingEngine) — Rust, Vulkan rendering, and hybrid CPU/GPU physics.
- [RustingBrain](https://github.com/RustingStudio/RustingBrain) — deep learning in Rust with CPU and GPU backends.
- [RustingShader](https://github.com/RustingStudio/RustingShader) — cinematic Minecraft graphics with Iris and GLSL.

## Shared guidance

- [Contributing](CONTRIBUTING.md)
- [Getting help](SUPPORT.md)
- [Community conduct](CODE_OF_CONDUCT.md)

GitHub uses the supported community files here as defaults for repositories that don't provide their own. Repository-specific guidance takes precedence.

The organization landing page lives in [profile/README.md](profile/README.md). Brand assets live in [assets](assets); the PNG avatar is ready to upload in the organization's profile settings.

The angular R logo is also available as [RustingStudio.svg](RustingStudio.svg) with a transparent background and [RustingStudio.png](RustingStudio.png) on charcoal.
